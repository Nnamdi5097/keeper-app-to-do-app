# Fullstack Task Manager & To-Do Application

🚀 **Live Web Application:** [https://my-keeper-app-chi.vercel.app/](https://my-keeper-app-chi.vercel.app/)

---

## 📌 Project Overview
A responsive fullstack task management web application designed to help users organize, track, and complete daily tasks efficiently with real-time updates and persistent storage.

---

## 🛠️ Tech Stack
* **Frontend:** React, CSS3 / Tailwind CSS
* **Backend:** Node.js, Express.js (REST API)
* **Database & Hosting:** MongoDB, Vercel / Render

---

## ✨ Key Features
* 📝 **CRUD Operations:** Create, read, update, and delete tasks seamlessly.
* ✅ **Task Completion & Filtering:** Mark tasks as complete and filter by status (All, Active, Completed).
* 📱 **Responsive Interface:** Optimized for mobile, tablet, and desktop browsers.
* ⚡ **RESTful API Backend:** Clean server architecture with persistent database integration.
